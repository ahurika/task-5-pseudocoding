# AI Verification Skill

## C1
Give AI the completed pseudocode and:
`Implement this exactly, one function per pseudocode block, no additional behaviour.`

## C2
Reverse-engineer the AI code without consulting the original pseudocode. Classify every difference as added, omitted, or ambiguity.

## C3
Run both implementations on five existing plus five new inputs. Resolve disagreements by tracing the pseudocode.

## C4
Explain the AI implementation from pseudocode only, with no code visible, for no more than five minutes.
