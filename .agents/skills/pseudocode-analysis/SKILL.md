# Pseudocode Analysis Skill

1. Identify exact function and version.
2. List inputs and meanings.
3. Identify outputs/errors.
4. Identify external calls and state changes.
5. Identify early exits, branches and loops.
6. Identify failure conditions.
7. Write numbered plain-English steps.
8. Hand-trace normal, edge and invalid inputs.
9. Compare against real execution where required.

Describe actual behaviour before intended behaviour.
