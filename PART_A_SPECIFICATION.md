# Part A Specification

## A1 — Own work
Create exactly:
```text
part-a/own/01-most-complex.md
part-a/own/02-money-or-authorisation.md
part-a/own/03-error-handling.md
```
For each record project/repository, source path, function, why selected, pseudocode, 3 traces, real execution, comparison, discrepancy and correction.

Each function needs:
- normal input;
- edge input;
- invalid input.

## A2 — Open source
Create:
```text
part-a/open-source/01-short.md
part-a/open-source/02-medium.md
part-a/open-source/03-difficult.md
```
Choose a library you actually use. First pass MUST be without AI.

After the first pass, compare with AI:
```text
part-a/open-source/01-ai-comparison.md
part-a/open-source/02-ai-comparison.md
part-a/open-source/03-ai-comparison.md
```
Record every meaningful difference, re-read the source, and identify the correct interpretation. Explicitly record AI mistakes.

## A3 — Planted bug
Create:
```text
part-a/planted-bug/01-actual-behaviour.md
part-a/planted-bug/02-expected-behaviour.md
part-a/planted-bug/03-bug-identification.md
```
Do not fix the function while describing actual behaviour. The bug is the difference between actual and expected pseudocode.
