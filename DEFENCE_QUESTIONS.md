# Task 5 Defence Questions

1. Pick any function from Part A. Give me an input and tell me what comes out, without looking at the code.
2. Show me the ambiguity you found in your own pseudocode in C2 and how you rewrote it.
3. Your implementation and the AI's disagreed on an input. Which was right, and how did you know?
4. Here is a function you have never seen. Pseudocode it for me now, out loud.

## Preparation
For any function be ready to state:
- inputs;
- output;
- side effects;
- failure conditions;
- numbered actions;
- branches;
- loops;
- early exits;
- external calls;
- state changes.

Also rehearse explaining the planted bug, an A2 AI mistake, a B2 step-to-code mapping, a C2 ambiguity and a C3 disagreement.
